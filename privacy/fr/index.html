Informations que nous collectons

Informations de compte

Lors de la création d'un compte, nous pouvons collecter :

  • Adresse e-mail
  • Identifiants d'authentification
  • Informations de compte Apple Sign-In
  • Informations de compte Google Sign-In

Contenu utilisateur

Nous pouvons collecter les informations que vous fournissez volontairement, notamment :

  • Ingrédients saisis dans l'application
  • Préférences de recettes
  • Recettes enregistrées
  • Recettes favorites
  • Listes de courses
  • Informations de planification des repas
  • Notes associées aux recettes

Informations d'achat

Les achats sont traités par Apple et Google.

Nous ne recevons pas les données complètes de carte de paiement.

Nous pouvons recevoir les informations de transaction nécessaires pour valider les achats et gérer les crédits.

Analytique et diagnostics

Nous pouvons collecter :

  • Type d'appareil
  • Système d'exploitation
  • Version de l'application
  • Rapports de plantage
  • Statistiques d'utilisation
  • Données d'interaction avec les fonctionnalités
  • Indicateurs de performance

Les prestataires d'analytique peuvent inclure :

  • Firebase Analytics
  • Firebase Crashlytics
  • RevenueCat
  • Microsoft Clarity

Traitement par IA

Les demandes de génération de recettes sont traitées via les services OpenAI.

Les informations soumises pour la génération de recettes peuvent être transmises à OpenAI uniquement dans le but de générer des suggestions de recettes.

Comment nous utilisons les informations

Nous utilisons les informations pour :

  • Fournir des services de génération de recettes
  • Authentifier les utilisateurs
  • Gérer les comptes
  • Délivrer les crédits achetés
  • Améliorer les performances de l'application
  • Diagnostiquer les problèmes techniques
  • Analyser l'utilisation des fonctionnalités
  • Assurer la sécurité
  • Respecter les obligations légales

Base juridique (RGPD)

Le cas échéant, nous traitons les données personnelles sur la base de :

  • L'exécution du contrat
  • Les intérêts légitimes
  • Les obligations légales
  • Le consentement de l'utilisateur lorsque cela est requis

Partage des données

Nous pouvons partager des informations avec des prestataires de services qui nous aident à exploiter Delixio, notamment :

  • Supabase
  • OpenAI
  • Google Firebase
  • RevenueCat
  • Microsoft Clarity
  • Apple App Store
  • Google Play Store

Nous ne vendons pas d'informations personnelles.

Transferts internationaux

Vos informations peuvent être traitées dans des pays situés hors de votre pays de résidence.

Lorsque cela est requis, des garanties appropriées seront mises en œuvre pour protéger les données personnelles.

Conservation des données

Nous conservons les informations personnelles uniquement aussi longtemps que nécessaire pour fournir les services, respecter les obligations légales, résoudre les litiges et faire respecter les accords.

Sécurité

Nous mettons en œuvre des mesures techniques et organisationnelles raisonnables destinées à protéger les informations personnelles.

Toutefois, aucune méthode de transmission ou de stockage n'est totalement sécurisée.

Vos droits

Selon votre juridiction, vous pouvez disposer de droits pour :

  • Accéder à vos informations
  • Corriger des informations inexactes
  • Supprimer vos informations
  • Limiter le traitement
  • Vous opposer au traitement
  • Recevoir une copie de vos données

Les demandes peuvent être envoyées à :

support@delixioapp.com

Suppression du compte

Les utilisateurs peuvent supprimer leur compte directement depuis l'application Delixio.

Vous pouvez également suivre la procédure indiquée sur notre page Supprimer le compte.

Confidentialité des enfants

Delixio n'est pas destiné aux enfants de moins de 13 ans.

Nous ne collectons pas sciemment d'informations personnelles concernant des enfants de moins de 13 ans.

Modifications de la présente Politique de confidentialité

Nous pouvons mettre à jour la présente Politique de confidentialité de temps à autre.

Les versions mises à jour seront publiées dans l'application et/ou sur notre site web.

Contact

Pour toute question relative à la confidentialité :
